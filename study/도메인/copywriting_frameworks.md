# Marketing Copywriting Frameworks

마케팅 메시지를 구조적으로 작성하기 위한 대표적인 프레임워크 정리.

---

# PAS Framework

Problem - Agitate - Solution

## Problem

고객이 가진 문제를 정의한다.

예)

"광고 비용은 증가하지만 실제 구매 전환율은 낮아지고 있습니다."

---

## Agitate

문제를 해결하지 않았을 때 발생하는 손실을 강조한다.

예)

"비효율적인 광고 운영은 불필요한 비용 증가와 고객 이탈로 이어집니다."

---

## Solution

제품이나 서비스가 문제를 해결하는 방법을 제안한다.

예)

"AI 기반 광고 최적화 플랫폼으로 광고 효율을 개선할 수 있습니다."

---

# 대표적인 Copywriting Framework

## AIDA

Attention
→ Interest
→ Desire
→ Action

고객의 관심을 구매 행동으로 연결하는 구조

---

## FAB

Feature
→ Advantage
→ Benefit

제품 기능을 고객 가치 중심으로 설명하는 구조

---

## BAB

Before
→ After
→ Bridge

현재 문제 상황과 개선된 미래를 대비시키는 구조
