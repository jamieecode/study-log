# Prompt Engineering Core Concepts

## 1. Foundational Prompting

### Role Driven Prompting

- **개념**: AI에게 특정 역할이나 전문적인 페르소나 부여해 답변의 톤앤매너, 깊이 제어
- **효과**: 특정 도메인에 특화된 정형화된 맥락의 답변 유도.
- **예시**
    
    ```tsx
    *당신은 10년 차 스타트업 전문 세무사입니다. 창업자를 위한 초기 절세 전략을 수립해 주세요.*
    ```
    

### Few-Shot Prompting

- **개념**: 사용자가 원하는 입출력 예시(Example)를 몇 개 제공하여 출력 형태를 학습시킴
- **효과**: 복잡한 포맷팅, 일관된 데이터 파싱, 감성 분석 등 정교한 결과물이 필요할 때 유용.
- **예시**
    
    ```
    입력: 사과 -> 출력: 과일
    입력: 자동차 -> 출력: 탈것
    입력: 노트북 -> 출력: 전자기기
    ```
    
- ***Zero-Shot Prompting:** 예시를 주지 않는 기본 형태*

### Directional Stimulus Prompting

- **개념**: 반드시 포함해야 하는 핵심 키워드나 조건을 미리 제시하여 답변의 방향을 제어하는 기법
- **효과**: 긴 글 요약이나 콘텐츠 생성 시 의도치 않은 방향으로 이탈하는 것을 방지.
- **예시**
    
    ```tsx
    *아래 본문을 요약하되, [비용 절감], [출시 일정], [마케팅] 이 세 가지 키워드를 반드시 중심으로 다뤄줘*
    ```

## 2. Advanced Reasoning

### Chain of Thought (CoT)

- **개념**: 정답을 바로 요구하지 않고, 문제를 해결하는 단계별 추론 과정(Step-by-Step)을 거치도록 유도
- **효과**: 수학적 계산, 논리 퀴즈, 복잡한 코드 아키텍처 설계 시 오답률(hallucination)을 획기적으로 낮춤.
- **예시**
    
    ```tsx
    문제를 단계적으로 해결하고, 최종 결론을 설명해 주세요.
    ```
    

### Tree of Thoughts (ToT)

- **개념**: CoT의 확장형. AI가 하나의 추론 직선을 따르는 것이 아니라 여러 개의 독립적인 생각 줄기(가지)를 뻗어 탐색하고 스스로 검증하며 최선의 경로를 찾아감
- **효과**: 브레인스토밍, 다각도 전략 수립, 복잡한 체스 문제 해결 등 고난도 문제 해결에 최적화

### Generated Knowledge Prompting

- **개념**: 본 질문에 답하기 전에, AI에게 이 주제와 관련된 배경지식이나 관련 팩트를 먼저 정리해 보라고 지시한 뒤, 그 지식을 기반으로 최종 답변을 도출하게 함
- **효과**: AI가 가진 사전 지식을 활성화하여 상식 검증이나 맥락 파악의 정확도를 향상
- **예시**
    
    ```tsx
    먼저 이 주제의 핵심 개념을 정리한 뒤, 이를 바탕으로 질문에 답해 주세요.
    ```

## 3. Iterative & Retrieval Techniques

### Feedback Loop (Self-Correction/Self-Refinement)

- **개념**: AI가 낸 1차 결과물을 인간이 평가하거나, AI 스스로 검증(Self-Evaluation)하게 하여 결과물을 지속적으로 수정·보정하는 반복 프로세스
- **효과**: 완성도 높은 보고서 작성, 코드 디버깅 및 리팩토링 시 오류 최소화.
- **예시**
    
    ```tsx
    방금 작성한 코드의
    
    - 성능
    - 보안
    - 가독성
    
    관점에서 개선한 뒤 최종 코드를 다시 작성해 주세요.
    ```
    

### Retrieval-Augmented Generation (RAG)

- **개념**: 외부 데이터베이스(DB)나 문서에서 실시간으로 검색된 최신/보안 데이터를 AI 프롬프트에 동적으로 주입하여 답변을 생성
- **효과**: AI 학습 데이터의 한계를 극복하고 최신 정보 반영 및 환각 현상(hallucination) 방지.

## 4. Modern Prompting Techniques

### Prompt Chaining

- **개념:** 하나의 큰 작업을 여러 개의 작은 작업으로 나누어 순차적으로 수행하는 기법
- **효과:** 복잡한 업무 자동화, 품질 향상, 유지보수 용이
- **예시**
    
    ```tsx
    요구사항 분석
    
    ↓
    
    기능 목록 작성
    
    ↓
    
    API 설계
    
    ↓
    
    React 컴포넌트 생성
    
    ↓
    
    테스트 코드 생성
    ```
    

### Structured Output

- **개념:** JSON, XML, Markdown 등 지정한 형식으로 응답하도록 요구하는 기법
- **효과:** 프로그램에서 바로 사용 가능, 파싱 오류 감소, API 연동에 적합
- **예시**
    
    ```tsx
    다음 형식의 JSON으로만 응답하세요.
    
    {
      "title": "",
      "summary": "",
      "keywords": []
    }
    ```
    

### Constraint Prompting

- **개념:** 반드시 지켜야 하는 조건이나 제한사항을 명확하게 제시하는 기법
- **효과:** 불필요한 출력 감소, 요구사항 충족률 향상
- **예시**
    
    ```tsx
    - 300자 이내
    - 표 사용
    - 예제 3개 포함
    - 코드 블록 사용
    ```

## 5. Agent & Tool-Based Prompting

### ReAct(Reason + Act)

- **개념:** 추론과 행동을 번갈아 수행하며 문제를 해결하는 에이전트 프롬프팅 기법
- 기존 프롬프트는 생각 → 답변, ReAct는 생각 → 검색 → 검색 결과 분석 → 추가 검색 → 최종답변처럼 여러 단계 반복해 문제 해결
- **효과:** 검색 활용, API 호출, 데이터베이스 조회, 코드/긴 작업 수행

### Tool Calling(Function Calling)

- **개념:** LLM이 필요한 순간 외부 함수 호출해 작업 수행
- **효과:** 최신 정보 조회, 결제, 예약, 메일발송 등 실제 서비스에 필수
- **예시**
    
    ```tsx
    오늘 서울 날씨 알려줘 -> 모델은 weather.getForecast("Seoul") 함수 호출하고 
    API 결과 받아 설명
    ```
    

### Agentic Workflow

- **개념:** AI가 하나의 답변만 생성하는 것이 아니라 계획을 세우고, 실행하고, 검토하는 과정을 반복하는 워크플로우
- 일반적인 프롬프트는 질문 → 답변이라면, Agent는 목표 설정 → 계획 수립 → 작업 실행 → 검토 → 수정 → 완료
- **효과:** 복잡한 프로젝트, 자동화 등에 뛰어난 성능

### Reflection Prompting

- **개념:** 생성한 결과를 스스로 평가하고 개선하도록 하는 자기 검토(Self-Reflction)기법
- **효과:** 코드 품질 향상, 문서 완성도 향상, 오류 감소, 논리 검증
- **예시**
    
    ```tsx
    이 답변을 검토하고
    
    - 오류
    - 빠진 내용
    - 개선점
    
    을 수정한 뒤 최종 답변을 다시 작성해 주세요.
    ```
    

### Multi-Agent Collaboration

- **개념:** 여러 AI 에이전트가 각자의 역할을 맡아 협업하며 문제를 해결하는 방식
- **효과:** 대규모 프로젝트 분업, 역할별 전문성 활용, 병렬작업을 통한 생산성 향
- **예시**
    
    ```tsx
    PM Agent
          │
          ▼
    Architecture Agent
          │
          ▼
    Backend Agent
          │
          ▼
    Frontend Agent
          │
          ▼
    QA Agent
    ```
    

### Memory-Augmented Prompting

- **개념:** 이전 대화, 사용자 정보, 작업 기록 등을 활용하여 일관성 있는 응답을 생성하는 기법
- **효과:** 개인화된 응답, 긴 대화 맥락 유지, 반복 설명 감소
- 사용자 선호도 반영, 프로젝트 진행 상황 이어가기, 장기적인 학습 및 코칭

### MCP(Model Context Protocol)

- **개념:** LLM이 다양한 외부 도구와 데이터 소스에 표준화된 방식으로 연결될 수 있도록 하는 프로토콜. 도구마다 별도의 연동 방식 구혀없이 일관된 인터페이스 제공
- **효과:** 다양한 도구와의 표준화된 연결, 에이전트 간 상호운용성 향상, 유지보수 비용 절감
- 파일 시스템 접근, 데이터베이스 조회, 디자인 도구(피그마) 연동
