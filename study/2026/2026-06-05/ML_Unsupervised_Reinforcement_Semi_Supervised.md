# ML_Unsupervised_Reinforcement_Semi_Supervised_Learning

## **비지도 학습 (Unsupervised Learning)**

정답(Label) 없이 데이터의 내부 구조와 패턴을 파악하는 학습 방식입니다.

### **차원 축소 (Dimensionality Reduction)**

- **PCA (주성분 분석)**
    - **개념**: 고차원 데이터를 정보 손실을 최소화하면서 저차원(2D, 3D 등)으로 압축하는 기법.
    - **목적**: 시각화, 학습 속도 향상, 노이즈 제거.
    - **특징**: 데이터의 분산(Variance)이 가장 큰 방향을 찾아 새로운 축으로 설정함.

### **연관 규칙 학습 (Association Rule Learning)**

- **Apriori**
    - **개념**: 데이터 간의 "함께 발생하는 규칙"을 찾는 기법.
    - **활용**: 장바구니 분석 (예: 맥주를 사는 사람은 기저귀를 같이 살 확률이 높다).
    - **지표**: 지지도(Support), 신뢰도(Confidence), 향상도(Lift)를 통해 규칙의 유효성을 평가.

## **강화 학습 (Reinforcement Learning)**

에이전트가 환경과 상호작용하며 보상(Reward)을 최대화하는 행동을 스스로 깨닫게 하는 학습 방식입니다.

### **주요 개념**

- **Agent (에이전트)**: 학습의 주체 (예: 게임 캐릭터, 자율주행차).
- **Environment (환경)**: 에이전트가 활동하는 무대.
- **State (상태)**: 에이전트가 처한 현재 상황.
- **Action (행동)**: 에이전트가 할 수 있는 선택.
- **Reward (보상)**: 행동의 결과에 따라 받는 점수 (+ 또는 -).

### **주요 기법**

- **Q-Learning**
    - **개념**: 특정 상태에서 어떤 행동을 했을 때 받을 기대 보상을 표(Q-Table)에 기록하며 학습함.
- **DQN (Deep Q-Network)**
    - **개념**: Q-Learning에 딥러닝(신경망)을 결합하여, 표로 정리하기 힘든 복잡하고 방대한 상태를 처리함.
    - **사례**: 벽돌깨기 게임, 알파고 초기 모델 등.

## **준지도 학습 (Semi-supervised Learning)**

라벨이 있는 데이터(소량)와 라벨이 없는 데이터(대량)를 동시에 활용하는 방식입니다.

- **Self-Training**: 라벨 있는 데이터로 학습한 모델이 라벨 없는 데이터의 정답을 예측(Pseudo-labeling)하고, 신뢰도가 높은 데이터를 다시 학습에 포함시켜 모델을 확장함.
