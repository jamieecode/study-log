# ML_Supervised_Learning

## **지도 학습 (Supervised Learning)**

### **1. 나이브 베이즈 (Naive Bayes)**

- **개념**: 베이즈 정리를 기반으로 한 조건부 확률 모델. 모든 특성이 독립적이라고 가정함
- **특징**: 스팸 메일 필터링, 텍스트 분류에 매우 강력함
- **장점**: 계산 속도가 매우 빠르고 데이터 양이 적어도 잘 작동함
- ‘Zero Frequency' 문제를 해결하기 위해 라플라스 스무딩이 필요
    - Zero Frequency:  학습 데이터에 없던 새로운 단어가 나타나면 해당 단어의 확률이 이 되고, 모든 확률의 곱셈으로 이루어지는 나이브 베이즈 특성상 최종 확률이 무조건 이 되는 치명적인 오류가 발생
    - 라플라스 스무딩 (Laplace Smoothing): 모든 단어의 빈도수에 (혹은 작은 상수)를 더해주는 기법

### **2. KNN (K-Nearest Neighbors)**

- **개념**: 새로운 데이터를 가장 가까운 K개의 이웃 데이터와 비교하여 분류/회귀함(유유상종)
- **특징**: 거리 계산 방식(유클리드, 맨해튼)에 따라 결과가 달라짐
- **핵심**: 데이터 **스케일링(Scaling)**이 필수임 (단위에 민감함)
- **장점**: 직관적이고 훈련 단계가 없음

### **3. 랜덤 포레스트 (Random Forest)**

- **개념**: 여러 개의 결정 트리(Decision Tree)를 만들고 다수결로 최종 결과를 결정하는 **배깅(Bagging)** 방식
- **특징**: "집단지성"을 이용하여 단일 트리의 과적합 문제를 해결
- **장점**: 성능이 안정적이고 데이터의 '특성 중요도'를 확인할 수 있음

### **4. XGBoost & LightGBM (Boosting)**

- **공통점**: 이전 모델의 오차를 다음 모델이 보완하는 **부스팅(Boosting)** 방식
- **XGBoost**: 강력한 성능과 과적합 방지 규제가 특징
- **LightGBM**: 'Leaf-wise' 성장 방식으로 대용량 데이터에서 XGBoost보다 훨씬 빠르고 가벼움
- **비교**: 데이터가 적으면 랜덤 포레스트, 많고 정교한 예측이 필요하면 부스팅 계열 권장

## **3. 핵심 전처리 기법**

- **Standardization (표준화)**: 평균 0, 표준편차 1로 변환 (거리 기반 알고리즘 필수)
- **Normalization (정규화)**: 0~1 사이 값으로 변환
