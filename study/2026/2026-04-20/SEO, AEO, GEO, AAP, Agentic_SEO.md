# SEO, AEO, GEO, AAP, Agentic SEO

# 1. SEO (Search Engine Optimization)

검색 엔진에서 웹사이트가 상위에 노출되도록 최적화하는 전략(검색 → 링크 클릭 → 사이트 방문)

### 목표

- 검색 결과 상위 노출
- 클릭 유도 (CTR 증가)

### 특징

- 키워드 중심
- 백링크 중요
- 콘텐츠 길이 / 구조 중요

---

# 2. AEO (Answer Engine Optimization)

검색 결과가 아닌 "답변 자체"로 선택되도록 최적화하는 방식(질문 → 직접 답변 노출)

- Google Featured Snippet
- People Also Ask
- ChatGPT / Perplexity 등 AI 답변 시스템

### 목표

- 클릭 없이 답변으로 노출

### 특징

- 질문형 콘텐츠 (What / How / Why)
- FAQ 구조
- 첫 문장에 결론 배치

---

# 3. GEO (Generative Engine Optimization)

AI 생성 모델이 콘텐츠를 학습/참조하도록 최적화하는 방식(콘텐츠 → AI 학습/참조 → 답변 생성에 반영)

- ChatGPT
- Claude
- Perplexity
- Google SGE

### 목표

- AI 답변 생성 시 참고 자료로 포함

### 특징

- 문맥 중심 콘텐츠
- 구조화된 정보
- entity 기반 설명

---

# 4. AAP (AI Answer Positioning)

AI가 답변을 생성할 때 특정 브랜드/콘텐츠를 "추천"하도록 만드는 전략(AI 답변 → 추천 리스트 포함)

### 목표

- AI 추천 영역에 포함
- "Top", "Best", "추천" 리스트에 등장

### 특징

- 비교 콘텐츠
- 브랜드 authority
- 리스트형 콘텐츠 (Top 10 등)

---

# 5. Agentic SEO

AI 에이전트가 단순 답변이 아니라 실제 행동(예약, 구매, 실행 등)을 수행하는 환경에 최적화하는 전략(AI 이해 → 의사결정 → 행동 실행)

- AI Agent 시스템
- 자동화 기반 AI 워크플로우

### 목표

- AI가 콘텐츠 기반으로 실제 행동 수행

### 예시

- 예약
- 구매
- 코드 실행
- 서비스 비교 및 선택
